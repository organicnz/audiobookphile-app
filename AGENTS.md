# AGENTS.md — Audiobookphile iOS app

Dual-platform audiobook player: one Swift module compiles for **iOS (native)**
and **Android (Skip transpilation)**.

## Non-negotiable constraints

1. **Skip guard discipline.** Apple-only frameworks (`WidgetKit`,
   `BGTaskScheduler`, App Intents, `AVFoundation` specifics, `UIKit`,
   `Sentry`) must sit behind `#if !SKIP && os(iOS)` with a Skip-compatible
   fallback, matching the existing pattern in `Sources/Audiobookphile`.
   Widget/intent extensions under `Darwin/` are native-only — never import
   Skip-transpiled app types into them.
2. **Both targets must build.** After changes run the same command CI runs:
   `xcodebuild build-for-testing -scheme Audiobookphile -destination "generic/platform=iOS Simulator" CODE_SIGNING_ALLOWED=NO -quiet`
   Use the toolchain under `/Applications/Xcode.app/Contents/Developer` (the
   repo sits under a `xcode` `.swift-version` pin, so `swift` on PATH already
   resolves there). **Do not use `swift build` / `swift test` at the package
   root** — the Skip 1.9.x graph links `SkipFoundation`/`SkipLib`/`SkipUnit`
   as static products from several targets, which SwiftPM rejects as library
   duplication. `xcodebuild` against `Project.xcworkspace` resolves the same
   graph correctly. CI enforces Skip verification.
3. **Commit messages** must be strict Conventional Commits (`type(scope): …`)
   — the commit-msg hook rejects combined `fix(a)+chore(b):` styles.
4. **No secrets in repo.** DSNs/keys flow through `Skip.env` generated by
   `ci_post_clone.sh` from Xcode Cloud env vars.
5. Hooks fail silently when truncated — read full git output; pre-commit runs
   SwiftLint/build, commit-msg validates convention, pre-push runs the full
   suite + security audit (needs the correct toolchain on PATH).

## Agent skills

Curated, reviewed skills live in `.agents/skills/` (see its README for
provenance, pinned commits, and the Skip caveat). `.claude/skills/*`
symlinks to them. Use them when working on:

- `swift-concurrency-pro` — any async/await, actor, or Task code
- `background-execution` — BGTaskScheduler / background audio work
- `app-intents` — `Sources/Audiobookphile/Intents/SiriIntents.swift`
- `widgets` — `Darwin/WidgetExtensionTemplates/AudiobookWidget.swift`

## Architecture map

- `ContentView.swift` — root tabs, mini-player, fullScreenCover presentation
- `Services/PlayerCoordinator.swift` — modal-presentation gating (black-screen fix)
- `Features/Player/AudioPlayerService.swift` — playback engine orchestration,
  seek-epoch invariants documented inline; treat them as contracts
- `Core/Telemetry/` — CrashReporter (local fallback) + TelemetryService
  (Sentry envelope transport); SentrySDK starts only when DSN configured
- Backend API contract: sibling repo `audiobookphile-backend` (Deno/Supabase)
